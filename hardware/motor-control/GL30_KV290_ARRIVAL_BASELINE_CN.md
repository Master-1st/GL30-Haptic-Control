## 3. 参数一致性与固件采用值

### 3.1 可直接互相校验的项目

- `3060 rpm / 12 V = 255 rpm/V`，所以表中的 255 rpm/V 与空载点完全一致。
- `0.08 N·m / 2.13 A = 0.03756 N·m/A`。
- `0.28 N·m / 7.4 A = 0.03784 N·m/A`。
- 两个转矩点都支持把 `Kt=0.038 N·m/A`作为首轮估算值。
- 若 `1.530 ohm / 330 uH`均为星形电机的线—线测量值，则 FOC 相值初始换算为：

  ```text
  Rphase = 1.530 / 2 = 0.765 ohm
  Lphase = 330 / 2 = 165 uH
  tau_e  = 165 uH / 0.765 ohm = 0.216 ms
  ```

  与厂家 `0.22 ms`一致。

### 3.2 不能写成已验证事实的项目

- 曲线标题为 `KV290@12VDC`，但 290 rpm/V 对应约 3480 rpm；当前基线与固件采用 `255 rpm/V` 一致，不把 `KV290` 当作实测 Ke 前置门槛，先在 EVM 上用低电流闭环逐步验证。
- `1000 / 255 = 3.92 V/krpm`，与表中 `3.73 V/krpm`相差约 4.9%。相/线、峰值/RMS 和驱动定义尚未对齐，不把此换算当作厂家参数错误。Ke 测量可在后续速度/电压模型需要时进行，不阻塞当前低速电流闭环。
- 厂家 7.4 A 点接近堵转端；即使驱动器标称 8 A peak，也没有证明电机、PCB、连接器、电源或散热能持续承受。

## 4. 替换电机的最小首测清单

| 顺序 | 保留的检查 | 判据与范围 |
| --- | --- | --- |
| 1 断电标记/初筛 | 三根相线固定标为 A/B/C，照片记录；缓慢手转；万用表看 AB、BC、CA 导通且阻值接近、相线与壳体无明显低阻 | 三相与驱动板断开后测量。星形三相互相导通是正常现象，不是短路证据；普通万用表仅排查开路/严重不平衡/碰壳，不宣称完成精密电阻或高压绝缘检测 |
| 2 编码器 | 只给控制器/编码器上电，功率关闭，慢转一圈读角度和诊断 | 方向一致、无异常跳变；0/16383回绕正常，静止允许少量噪声。无须测完整线性、偏心或重装磁钢；新线束端点仍需核对 |
| 3 台架准备/对齐 | 沿用 NUCLEO/TI 手册，先无电机三相执行 PREPARE 验证驱动/采样，再断电接电机，重新 PREPARE → ALIGN | 电流零点与驱动健康通过；本台电机重新识别方向和 RAM 电角零位；厂家通用参数不能替代该对齐 |
| 4 短脉冲/停止 | 初次不装握环，可靠固定定子；先 +50 mA/200 ms，再单独 -50 mA/200 ms；检查停止、B1释放和许可超时保护 | 实际电流/方向与指令可解释、无异常振荡/发热、结束和故障后确实关闭输出。每次准备/接线以当前联调手册为准 |

第一步无需强制四线法或再次200 mA精测，R参数继续用厂家1.53 Ω。若普通万用表读数明显不一致，先排除表笔/接触电阻，再仅对异常项复测；不用百分比门槛去验收未补偿的低阻档读数。

如果选择沿用熟悉的200 mA方法，只记录 **AB、BC、CA** 各一次稳态电压即可，按厂家值预计约0.306 V，三次的另一根相线保持悬空。它是可选的低阻复核，不必再做另一套电阻实验；线阻不决定相序。相线A/B/C是本项目标记，不需要预先查出厂家“真正的UVW”。相线接到输出后的对应关系固定记录，任何换线都断电并重做ALIGN。

现在不测：电感、反电势/定速拖动、Kt/完整扭矩曲线、额定/峰值堵转、编码器全角线性、磁场气隙/偏心、500 V耐压。不买LCR表或测功机，不拆原厂编码器，不写OTP。出现异常时才针对原因补测；电流零点、方向/电角对齐和实际关断不能省。

这四组是进入**低电流FOC联调**的检查，不是连续工作、额定性能或成品安全验收。完整执行顺序见[NUCLEO/TI首测手册](../../firmware-stm32/bench/NUCLEO_G474RE_FOC/README_CN.md)。

### 4.1 已退样品记录（2026-09-01，不适用于替换电机）

用户报告以 `0.200 A` 直流电流依次测得三组线—线端电压 `0.3069 V / 0.3090 V / 0.3099 V`。当前未提供线色/相名、电流源精度和四线接法说明，因此先以 1/2/3 号线对记录，不把它写成温度修正后的标定值。

| 线对 | 端电压 | 按 `R=V/0.200 A` 换算 |
| --- | ---: | ---: |
| 1 | 0.3069 V | 1.5345 ohm |
| 2 | 0.3090 V | 1.5450 ohm |
| 3 | 0.3099 V | 1.5495 ohm |
| 平均 | 0.3086 V | 1.5430 ohm |

- 最大—最小极差为 `0.0150 ohm`，相对平均值约 `0.97%`，明显小于当前 `<5%` 初筛门槛。
- 平均值比厂家 `1.530 ohm` 高约 `0.85%`；在尚未温度修正和校验实际电流前，不构成参数冲突。
- 若仅按本次均值折算，等效相电阻约 `0.7715 ohm`；与固件当前 `0.765 ohm` 初值只差约 `0.85%`，不足以单独触发 PI 修改。
- 原样品结论为 `PASS_INITIAL_RESISTANCE_SYMMETRY / RETIRED_SAMPLE`。它只证明已退电机在当时条件下三组直流线阻对称，不能给替换电机判定通过，也不证明其他参数或功率级。
- 当前线电感状态保留为 `VENDOR_DEFAULT_330_UH / NOT_MEASURED`；厂家线阻、线感和 `0.22 ms` 电气时间常数互相自洽，因此允许在现有低带宽、低电流边界下延期测量。
