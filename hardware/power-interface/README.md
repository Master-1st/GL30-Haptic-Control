# Power Interface

当前初值：12 V 母线、14.4 V 硬件制动、16.0 V 硬件关断；最终值由回灌能量、温升和故障注入收敛。

INA228 放在 12 V 电机母线入口：5 mΩ 四端 Kelvin 分流器，A0/A1 接 GND（7-bit 地址 `0x40`），VBUS 接负载侧母线，VS 接 3V3A，ALERT 首板只留测试点。固件当前使用 ±163.84 mV 档、50 µA/LSB、约 556 Hz 内部更新并以 100 Hz 遥测。INA228 只记录双向功率、能量和电荷，不能替代 DRV8316、外部窗口比较器或 TIM1 BKIN。

HUSB238 采用电阻/器件配置请求 15 V，不占 STM32 I2C1；首板必须单独测 PDO 协商、15 V 轨和断连行为。
