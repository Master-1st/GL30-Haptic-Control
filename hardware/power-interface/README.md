# Wireless Power Interface

当前产品默认改为 **3S 电池供电的完整无线力反馈**。以下参数是无实物阶段的首板默认，不是量产冻结或安全认证结论。

## 唯一默认架构

```text
单个后置 USB-C（PD + USB2）
  ├─ CC → HUSB238，请求 15 V
  ├─ D+/D- → ESP32-S3 USB
  └─ 15 V → 输入保护 → BQ25798 3S buck-boost charger
                         ├─ BAT ↔ 3S 电芯组 + BQ77915 保护/均衡 + NTC
                         └─ SYS → 逻辑 Buck/LDO → ESP32/AMOLED/STM32
                                └─ 外部双向高侧隔离开关
                                   → INA228 → MOTOR_BUS → DRV8316 → GL30

MOTOR_BUS → 独立硬件比较器 → 制动 MOSFET + 脉冲电阻
          → 独立过压关断 / TIM1 BKIN
          → TVS 仅吸收短尖峰
```

选择 `SYS` 作为首板系统负载节点，是因为它是 BQ25798 官方定义的系统输出，支持输入与电池补电，也避免把电机负载混入 BAT 端后破坏充电终止判断。它**不是已经证明能承受电机回灌**：电机前保留外部双向隔离开关，MOTOR_BUS 保留独立制动耗能，首板必须做 SYS/BAT A/B 脉冲与回灌测试；失败则改独立电池母线，不保留双实现。

官方依据：

- [BQ25798：1–4S、5 A、buck-boost、power path、QON/ship mode](https://www.ti.com/product/BQ25798)
- [BQ77915：3–5S、独立保护、温度保护与自主均衡](https://www.ti.com/product/BQ77915)
- [DRV8316：4.5–35 V 工作、8 A 峰值三相驱动](https://www.ti.com/product/DRV8316)

Waveshare 模块的 3.7 V 单节电池口不进入产品电机电源链，正式装机时由主板稳压供电，避免两套充电器和两块电池互相反灌。

正面底部灯条属于逻辑电源域，建议由可关断恒流/负载开关驱动；关机时默认熄灭，仅后侧充电指示允许由常开低功耗域控制。灯条亮度、电流和对续航的影响必须在整机功耗表中单独测量，当前不冻结 LED 型号或数量。

| --- | ---: | --- |
| 电池串数 | 3S | 架构冻结；2S 升压和 4S 降压不作为首板 |
| 标称/运行电压 | 11.1 V；约 9.0–12.6 V | 9 V 力矩与速度待实测 |
| CAD 电池参考 | 800 mAh，公开尺寸 80×20×16 mm | 仅机械参考；正式电芯/包未冻结 |

| 最低放电能力 | 5 A 连续、15 A/200 ms 脉冲 | 依据额定母线功率的保守起点；最终看母线实测而不是相电流直接换算 |
| 原型充电 CV | 12.45 V（4.15 V/cell） | 为寿命和回灌留余量；12.60 V 需在回灌测试后决定 |
| 原型充电电流 | 0.4 A | 约 0.5C，优先降低小壳体充电温升 |
| 低压警告/停止目标 | 9.6 V / 9.0 V | 与选定 BMS、电芯压降联调 |
| 当前固件高母线 warning | 13.2 V，仅看电压 | 已构建，但还不是针对 3S 回灌完成的策略 |
| 3S 回灌预警目标 | 12.8 V 且母线电流为负 | 尚未进入固件；先用台架确定噪声、方向和迟滞，不能作为唯一保护 |
| 硬件制动/硬关断 | 当前仍为 14.4 V / 16.0 V 初值 | 必须按 BMS、BQ25798 反向行为和回灌能量重算电阻及比较器 |

800 mAh 只是为了优先满足缩小体积并建立统一 CAD 包络。没有平均功率和目标续航前，不冻结 30–40 Wh；如果实测峰值压降、温升或续航不足，再以 `能量 = 平均功率 × 目标时间 / 可用比例 / 效率` 计算容量，并重新做整机碰撞，不凭感觉放大电池。

## 回灌不可省略的边界

GL30 被手指反拖、快速反向或主动制动时会向 MOTOR_BUS 回送能量。任何一种情况都不能单独作为安全答案：

- 电池未满不等于永远能吸收回灌；
- BMS 可能在满电、低温或故障时断开；
- BQ25798 的 5 A 充电能力不等于 SYS 可以吸收电机反向能量；
- TVS 只能处理尖峰，不能承担连续制动；
- MCU 软件关断不能覆盖掉电和程序失控。

因此制动电阻、MOSFET、硬件比较器和过压关断位于 `MOTOR_BUS`，在电机高侧开关断开后仍应能处理关机反拖。比较器偏置和泄放路径必须由 MOTOR_BUS 或独立常开安全域供电，不能依赖已经关机的主 MCU。

INA228 继续放在 MOTOR_BUS 入口：5 mΩ 四端 Kelvin 分流器，记录双向电流、功率、能量和电荷；它不能代替 DRV8316、外部比较器、BMS 或 TIM1 BKIN。

## 电源键与关机

- 后侧单独设置凹入式 `PWR/QON` 键，正面没有电源键。
- 关机时短按只唤醒/显示状态，长按约 2 s 由固件先停转、确认 DRV 安全，再命令 BQ25798 进入 ship mode。
- 关机状态按住 QON 约 1 s 唤醒；插入 USB-C 也可退出 ship mode。
- 超长按使用 BQ25798 的系统电源复位能力，硬件安全链继续保持 DRV 关闭；具体按键时序必须在 EVM/首板验证。
- 外部 ship FET、BMS 和充电器属于常开低功耗域；目标关机静态电流小于 100 µA，但当前没有实测证据。

## 首板必须通过

1. 9.0/10.5/12.45 V 下的目标触觉、母线峰值、相电流和温升。
2. 电池满电/低电、USB 插入/拔出、无电池时的启动和安全禁止。
3. 电机接 SYS 与独立电池轨的脉冲负载、充电终止和回灌 A/B；只保留通过的一种。
4. 满电手动反拖、快速反向、主动制动和关机反拖的母线电压/负电流/能量。
5. BMS OV/UV/OCD/SCD、BQ25798 故障、隔离开关失效和制动电阻过温注入。
6. Wi-Fi/BLE、USB2、AMOLED 和 40 kHz FOC 同时工作时的 EMC/丢包/复位检查。

在以上证据完成前，本文件只能支持 `WIRELESS_POWER_DEFAULT + CAD_CHECKED + BUILD_ONLY`，不能写成续航、力矩、热、回灌或产品安全已经验证。
