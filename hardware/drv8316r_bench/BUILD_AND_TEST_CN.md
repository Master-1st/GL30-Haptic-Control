# GL30 DRV8316R 验证子板：制作、焊接与测试

## 1. 下单前

- PCB：4 层、1.6 mm、外层 1 oz 起步、阻焊绿色、建议沉金；尺寸按实际布局，目标约 70×55 mm。
- U1 必须让 SMT 厂贴，或用钢网+回流台；不要用烙铁拖焊中心裸露焊盘冒充合格贴装。
- 外周 TH 端子和测试环可手焊。装配图必须标出 J_PWR 正负、电机 A/B/C、U1 1 脚、D1/TVS 极性。
- DRV8316R、TLV1704、电容的耐压和温度等级按 BOM 核对；DRV8316T 不可代换。F1 必须是有明确 I²t 的 3 A 延时型，首次上电仍用限流电源缓升。
- 让 PCB 厂对 U1 热过孔做底面盖油/填孔能力确认；不确认就先让贴片厂评估吸锡风险。

需要的台架：可限流电源、万用表、至少 100 MHz 示波器、10×探头短地弹簧、逻辑分析仪、可调 0–3.3 V 注入源、三个同批次 `10 Ω/50 W` 低感电阻和散热板。首次测试不接电机。

## 2. 焊后不开电检查

1. 显微镜检查 U1 四边、中心焊盘回流痕迹、D1/TVS、电解电容极性和 1 脚。
2. 万用表电阻档检查 `VM_RAW-GND`、`VM-GND`、`3V3_CTRL-GND`、OUTA/B/C 对地；电容充电导致读数变化正常，稳定近 0 Ω 不正常。
3. 二极管档确认 D1 只允许 VM_RAW 向 VM 正向导通。
4. 检查 HARD_FAULT_N 对 3V3_CTRL 是 2.2 kΩ 量级；DRVOFF 对 3V3_CTRL 是 10 kΩ；六 PWM 对 GND 各是 100 kΩ 量级。
5. 检查 SW_BK 到 FB_BK 为 22 Ω；FB_BK 到 GND_BK 能看到 22 µF 充电行为。

任一近短路、方向不明或 QFN 桥连，停止上电。

## 3. 只上 3V3_CTRL

VM 保持断开，电源给 `3V3_CTRL=3.3 V`，限流 20 mA：

- DRVOFF 必须高于 `2.7 V`；10 kΩ 外部上拉与芯片内部下拉会使它略低于 3.3 V，但仍应明显高于官方 `VIH=1.5 V`。
- CS_N 和 HARD_FAULT_N 应接近 3.3 V。
- nSLEEP 应在约 1 ms RC 后升到至少 `2.6 V`；断开 SJ_WAKE 后应回到 0 V。
- 六个 U1 侧 PWM 应为 0 V。
- 记录 3V3 供电电流并摸查 U1 是否反向灌电发热；3V3 单独上电异常时不加 VM。

若 3V3 电流超限或任一默认态不对，不加 VM。

## 4. 首次 VM 静态上电

保持 DRVOFF 高、PWM 全低。先 3V3，再从 J_PWR 输入限流电源，调高 `VM_RAW` 直到 TP_VM=`5.0 V`，限流 `50 mA`；不要接电机/假负载。后续所有母线数字也都以 TP_VM 为准，台源读数需补偿 SS56 压降。

除顺序上电外，再用示波器做一次 VM/3V3 同时及错相上电：同时观察 nSLEEP、DRVOFF、任一高/低 PWM 与对应 OUT，相输出不得出现有效导通毛刺。

依次测：

| 点 | 预期 |
| --- | --- |
| VM | TP_VM=`5.0 V`；VM_RAW 比它高一个 D1 压降 |
| AVDD | `3.1–3.465 V` |
| VREF | 接近 AVDD |
| CP−VM | 约 `3.6–5.25 V`，以数据手册范围为准 |
| SOA/B/C | 稳定在 AVDD/2 附近 |
| V_LOW | 约 `0.573/3.3×AVDD` |
| V_HIGH | 约 `2.727/3.3×AVDD` |
| VBUS_SENSE | 约 VM/6 |
| HARD_FAULT_N | 唤醒期间允许短暂低，稳定后应高 |
| OUTA/B/C | DRVOFF 高时高阻，不应主动开关 |

记录总电流和 U1/D1/TLV1704 温度。任何持续 nFAULT、AVDD 不稳、CP 异常、输出开关或发热，立即断 VM。

## 5. SPI 与固件关断态

按 [控制接口表](CONTROL_HEADER_PINOUT.csv) 接 STM32；GND 先接、3V3 次之、信号最后接。VM 仍 5 V/50 mA，DRVOFF 保持高。

产品固件当前应继续显示工厂编码器 `PENDING_VENDOR`，禁止 arm、MOE 关闭。这不是失败。应验证：

- SPI Mode 1、5 MHz、16 bit 帧波形正确。
- 可配置并回读 `CTRL2=0x68`、`CTRL3=0x5F`、`CTRL4=0x10`、`CTRL5=0x02`、`CTRL6=0x01`、`CTRL10=0x00`。
- `CTRL6 bit0=1` 后 Buck 被禁用，但板上 22 Ω/22 µF 仍保留。
- STAT0/1/2 无未知故障；DRVOFF 高、TIM1 MOE 低。

SPI 不通时先查 CS 极性、Mode 1、16 bit、GND 和线长，不先改寄存器表。

## 6. 比较器逐路注入

不接电机。断电后拆掉对应 `R_SOx_LINK` 0 Ω，再上 3V3 和 5 V VM，从 SOx_FANOUT 用低阻源注入。每次只测一相：

先测并记录本板实际 AVDD，不要假定恰好 3.300 V：

1. 注入 `0.50×AVDD`：HARD_FAULT_N 应高。
2. 注入 `0.20×AVDD`、`0.80×AVDD`：不应触发。
3. 缓慢向下扫，记录 HARD_FAULT_N 下降点；首板电阻计算目标为 `21/121×AVDD`，即 `0.17355×AVDD ± 25 mV`。
4. 缓慢向上扫，记录下降点；首板电阻计算目标为 `100/121×AVDD`，即 `0.82645×AVDD ± 25 mV`。
5. 在阈值附近小幅往返，示波器记录 HARD_FAULT_N 是否抖动；第一次低电平后 TIM1 MOE 必须保持关闭，不能自动重新使能。
6. 对 A/B/C 六个比较器重复；同时核对 STM32 PB12 和 TIM1 BIF。

测完断电并把三个 0 Ω 恢复。禁止在 0 Ω 未拆时用强驱动源硬灌 SO_RAW。

母线 16 V 比较器先不要直接把整板升到 16 V。先测本板 `3V3_CTRL` 和 `VBUS_TRIP`；在 VM=5 V 时用带电流限制的低阻源直接驱动 `VBUS_DIV_RAW` 到 `VBUS_TRIP−50 mV`/`VBUS_TRIP+50 mV`，确认前者释放、后者拉低。再用可限流 VM 缓慢升压做一次真实交叉验证，记录实际阈值，并与 `VM_TRIP=6×VBUS_TRIP` 对照。目标是 `15.5–16.5 V`；超出该区间就在任何有功率测试前重配 23.7 kΩ 阈值电阻。18 V 只是 DRVOFF 高、输出 Hi-Z 的停止上限，不是运行点。

## 7. 无电机假负载

只有在以下条件全部满足后进行：SPI/静态/注入均通过；工厂编码器后端 `control_ready=true`；电角零位有效；产品固件没有安全绕过。

三只 `10 Ω/50 W` 低感电阻接成浮置星形：三个外端分别接 OUTA/B/C，星点不接 GND。固定到散热板。电源从 `9 V/0.2 A` 限流开始。

示波器检查：40 kHz、六路互补关系、实际死区、OUTA/B/C、SOA/B/C、ADC_SAMPLE_TRIG、HARD_FAULT_N。任何相位同时导通、过冲接近器件额定、SOx 饱和、nFAULT 或异常温升立即停止。

当前编码器仍 PENDING 时，只完成关断态、SPI、ADC 零点、比较器和 BKIN 输入验证；不能为了“今天看到 PWM”加入隐藏 bench bypass。

## 8. 实电机推进顺序

1. 空载固定电机，9 V/0.2 A；确认编码器方向、极对数和电角零位。
2. 小幅 q 轴电流，核对三相电流符号/增益和转矩方向；用已知电流测出三相 CSA 实际零点和增益，再把实测 V_LOW/V_HIGH 换算为动作电流。
3. 逐级把限流升到 0.5 A、1.0 A、1.6 A；每级记录 U1、D1、连接器和 PCB 温升。若任一相实测硬件动作点低于约 `1.65 A`，在有功率升流前先把软件软限流降到 `1.5 A`，或按实测增益重配阈值电阻，不能让两个限制在公差区互相打架。
4. 注入 nFAULT/BKIN/通信断线/编码器断线，测触发到相输出关断延迟；故障后不得自动重新使能。
5. 最后才测快速拨动与回灌；验证板没有 14.4 V 制动电阻时，必须用低能量、限速和可吸收电源，不能把 TVS 当制动器。

## 9. 哪些结论能带到正式版

可以带走：接口方向、SPI 寄存器、CSA 标度、比较器实际阈值、BKIN 极性/延迟、初始死区、低压波形、功率器件温升趋势和测试方法。

不能直接带走：最终铜厚/尺寸、外壳内温升、EMI、连续 2 A 能力、真实再生制动、工厂编码器接口、电角零位、认证和量产良率。正式产品板仍需按相同门重新测，不得用验证子板结果代替。
