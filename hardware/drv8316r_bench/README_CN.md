# GL30 DRV8316R 验证子板

## 1. 这块板解决什么问题

`GL30_DRV8316R_BENCH_V1` 是 GL30 AMOLED V7 的低成本电机驱动验证板，用来在正式产品主板投板前闭合以下接口和风险：

- STM32G474 的 6-PWM、SPI3、三路同步电流采样与 `TIM1_BKIN`。
- DRV8316R 的上电、SPI 配置/回读、`DRVOFF`、`nFAULT`、三路 CSA 和三相功率输出。
- 不依赖 CPU 运算的三相 SOx 窗口比较器，经 TIM1 硬件 BKIN 异步关断 PWM。
- `16.0 V` 母线硬件故障比较器和低有效 `HARD_FAULT_N` 线与链。
- 焊接、去耦、热、接地、反接保护、测试点和故障注入方法。

这不是正式产品主板，也不是官方 DRV8316REVM 的仿冒复刻。它减少的是“接口和保护原理不确定性”，不能预先替代实物的温升、EMI、再生能量、编码器、电机闭环或认证测试。

## 2. 当前冻结

| 项目 | 当前值 |
| --- | --- |
| 驱动器 | `DRV8316RRGFR`，SPI 版本；不得替换成 `DRV8316T` |
| 母线范围 | 以下均指 D1 后的 `VM`：有功率运行 `6.0–15.5 V`，标称 `12 V`；`5 V` 只作静态验证，`16 V` 应触发硬故障，`18 V` 只作 Hi-Z 限流耐受/阈值扫描上限 |
| 项目电流 | 软件 `1.6 A`；外部窗口首板名义 `1.8 A`，实测后换阻值；DRV 内部 OCP 只作短路层 |
| PWM | 6-PWM，中心对齐 `40 kHz`，固件初始死区 `500 ns` |
| SPI | Mode 1，`5 MHz`，16 bit，偶校验 |
| CSA | VREF=`AVDD`，零点约 `AVDD/2`，增益 `0.6 V/A` |
| 过流阈值 | 首板 `V_LOW≈0.573 V`，`V_HIGH≈2.727 V`；名义约 `±1.80 A` |
| 母线故障 | `VBUS_SENSE=VM/6`，`VBUS_TRIP≈2.668 V`，约 `16.0 V` |
| 安全默认态 | `nSLEEP` 有下拉和延时；`DRVOFF` 外部上拉；PWM 下拉；BKIN 低有效 |
| PCB | 约 `70 mm × 55 mm`，4 层；L2 连续 GND，VM 只在功率区局部宽铜 |

所有电压、电流、RC、阈值和死区都是首板输入值，必须按 [制作与测试手册](BUILD_AND_TEST_CN.md) 实测后才能冻结到正式版。

### 当前首板阈值取舍

- 接受的硬修订：`DRVOFF` 外部上拉由原架构的 100 kΩ 改为 `10 kΩ`。TI 给出该输入内部约 70–130 kΩ 下拉，100 kΩ 外部上拉会形成不可靠分压。
- 接受的边界修订：过流首板仍取名义 `±1.8 A`，但把 AVDD、CSA 和比较器公差都计入后，只能标为粗略 `1.47–2.17 A`；必须先实测再升到软件 1.6 A 上限。
- 不采用名义 2.0 A 默认值：它可避免 1.6 A 附近的安全侧误锁，但最坏动作点可能接近 2.4 A，偏离本项目约 2 A 的硬件保护目标。验证板优先接受“可能早停、可换电阻”，不接受“可能过晚保护”。
- 不在首板加模拟滞回或 TIM1 BKIN 数字滤波：当前硬件第一次低电平即清 MOE，自动恢复关闭，故障状态由固件锁存；首板先测毛刺和误触发。滤波会同时推迟真实 nFAULT/过流脉冲，不能无波形依据加入。
- 保留 nSLEEP 的 `10 kΩ/100 kΩ/100 nF`：计入芯片内部下拉及 3V3_CTRL 最低 3.1 V 后，稳态仍约 2.66 V，高于官方保证的 1.6 V 高阈值；同时保留约 1 ms 的上电顺序裕量。

以上取舍以 TI 官方资料、阈值最坏情况计算和可测停止条件为依据。Buck、低压余量、浪涌、上电顺序和反灌问题均已落实到当前指南；与官方参数冲突的建议不作为设计输入。

## 3. 为什么不是直接买官方 EVM

官方 DRV8316REVM 最适合做“TI 原板行为对照”，但不是完成 GL30 的唯一途径。自制板保留官方数据手册要求的 DRV 外围，并增加 GL30 必需的外部电流窗口比较器、`HARD_FAULT_N` 和直接 STM32 接口，成本主要集中在 DRV 芯片、两片比较器和 SMT 贴装。SOx 来自集成低侧电流检测，其有效区间和建立时间仍受 DRV 工作状态约束，所以该比较器不能替代 DRV 内部短路 OCP，也不能被描述为完全独立于驱动器的电流传感器。

有条件时借用一块官方 EVM 做 A/B 对照仍然有价值，尤其是排查自制 PCB 焊接、热或布局问题；没有官方 EVM 不妨碍完成静态、SPI、ADC、比较器和低压假负载验证。

来源不明、不给原理图且无法确认是 `DRV8316R` 的低价模块不接受。它通常缺少三路 CSA、`DRVOFF`、完整 SPI、可核算的外部过流保护或可追溯布局，省下的费用会转化成不可定位风险。

## 5. 设计边界

已能在无实物阶段完成：电气冻结、阈值计算、网络映射、画图规则、接线和测试门。KiCad 源文件、制造文件、BOM 位号与 ERC/DRC 由用户按本指南画完后产生，再交给本任务复审。

必须等实物：QFN 焊接质量、静态电流、各电源轨、SPI 波形、CSA 零点/增益、比较器实际阈值、BKIN 延迟、相节点过冲、二极管和芯片温升、低感假负载、工厂编码器接口、电角零位、真实电机和再生制动。

当前产品固件仍保持工厂编码器 `PENDING_VENDOR` 与 `GL30_ELECTRICAL_ZERO_VALID=0`，因此会持续禁止 arm、保持 `TIM1 MOE` 关闭和 DRV safe-off。这是正确的安全行为，不为验证板偷偷增加绕过。
