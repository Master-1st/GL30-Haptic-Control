# GL30 日照金山表盘、循环圆环菜单与烤箱旋钮演示

日期：2026-09-10。原生 HTML/CSS/JavaScript，图标和旋钮为 SVG，照片表盘使用项目内置的日照金山背景，无远端运行依赖。双击同目录 `index.html` 即可打开，整个 `preview` 文件夹需一起保留。

仓库根目录可启动 HTTP 预览：

```powershell
python -m http.server 8768 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8768/firmware-esp32/ui/preview/`，已有页面刷新即可加载当前版本。

## 如何体验

1. 进入时显示满屏日照金山照片表盘：大号本地时间、日期与秒数，半透明区域显示示例天气和后台计时。背景为内置 image_gen 生成的 1254×1254 素材，不代表某个地点的实时画面。天气尚未联网，不代表当地实况。
2. 单击外环进入黑底圆环菜单；转动选择计时器、音量、秒表、闹钟、天气、手感、设置、日历、灯效调整，再单击打开。九项按 40° 间隔无限循环，前方图标放大、后方缩小；支持连续多圈和反向跨首尾。首次默认计时器，返回时保留当前应用位置。菜单转动只选择，桌面转动不修改后台应用。菜单外灯只有一个蓝色指针，不铺彩色光带。
3. 双击返回上一级：应用→菜单→桌面；桌面双击保持桌面。单击等待约 300 ms，以免双击先误执行一次确定。长按暂未设置，松手后也不补发单击。
4. 计时器从零设定，一圈 60 分钟，范围 0–360 分钟，显示 `HH:MM:SS`；单击开始/暂停/继续，完成后单击清零。运行中自动往回转，手动逆转减时、顺转加时，暂停也可调整。到零不再减小，逆转显示模拟止挡和轻微回弹，顺转立即重新设时。
5. 时间/音量、屏内圈、模拟旋钮及外侧光带共用坐标。蓝色始终是最前端，后方连续铺色；六个小时圈分别为橙、金、绿、紫、玫红、浅柠黄，外灯当前段与屏内当前圈同色。音量 33% 对应 118.8°。
6. 返回桌面、菜单或切换应用都不停止后台计时，剩余时间和独立暂停/继续入口保持可见。旋钮只跟随前台页面：桌面归中、菜单跟随可见圆环、计时/音量显示当前值；到时进入计时完成画面。
7. 后键或“熄屏”同时关闭屏幕和灯带；计时继续。熄屏后的首次单击或双击只唤醒，长按不唤醒；到时保持原熄屏状态。
8. 外环拖动、滚轮、方向键用于转动；空格/回车及“确定”按钮使用相同的单击/双击/长按规则。中央玻璃不接受启动操作，拖动结束不会被当作按压。Esc、右侧“返回”是直接返回命令。
9. 四侧快捷键保留：左上计时器、左下音量、右上增加、右下减少；音量单击切换静音，调节会解除静音。网页仅模拟音量，不控制电脑声音。
10. “看一次完整演示”把 90 分钟以明确标注的 450× 在 12 秒内演示；普通计时进行中不能被覆盖。输入检查可模拟断连/故障和减少动态效果；故障解除后需要手动恢复计时。
11. 秒表显示 `HH:MM:SS.xx`，单击启动/暂停/继续，按钮清零；后台与熄屏继续，和倒计时独立运行，不受 450× 演示倍率影响。故障暂停，解除后需手动继续。日历显示电脑本地日期，天气明确为示例；闹钟、手感、设置为占位页，尚不提供提醒或参数控制。
12. 灯效调整为可操作页面：旋转选择效果/颜色/亮度，单击进入调整，再单击确认；双击先退出调整，再双击回菜单。四种效果为随功能、常亮、呼吸、流动，提供六种颜色和 0–100% 亮度（旋转每格 5%）。选择即生效，并在本次页面会话内保留，刷新恢复默认。常亮/呼吸/流动延续到桌面和辅助应用，菜单固定单蓝指针，计时器/音量固定数值色带；亮度统一作用于灯环。0% 只关灯，不关屏幕。

## 输入与状态契约

- `page` 分为 `home/menu/app`，与计时阶段 `setting/running/paused/done` 分开。导航不重建或清零应用。
- `APPS` 定义九项入口；`menuPosition` 保留连续浮点圈数，只对 `menuIndex` 取正模。直接选择走最近路径，正好相对的两项固定走负向半圈。拖动直接跟随；滚轮/方向键缓动时图标、模拟外环和蓝指针使用同一个可见位置，减少动态效果时立即就位。
- 秒表使用独立的 `stopwatchElapsed/stopwatchRunning`。辅助页转动及占位页单击不修改计时器或音量，秒表清零也不停止后台倒计时。
- 稳定按下/释放各 20 ms 去抖，短按释放后等待 300 ms。第二次按下在窗口内即暂停单击判定，第二次短释放只发一个双击。
- 按住 650 ms 识别为长按但不执行应用动作；短按后第二次长按会消耗前一次待定单击。初始已经按住则先等释放，不生成一次启动；持续按住不连发。
- 外环移动超过 6 CSS px 转为拖动并取消按压。转动、直接导航、断连/故障/熄屏状态变化、指针取消、失焦和页面可见性变化会取消待确认的旧输入。稳定的故障/熄屏状态不反复清除新手势，所以导航与唤醒仍可使用。
- 到时优先进入完成画面并取消旧输入。包括在音量页等待静音确认、菜单等待打开应用以及未结束的按压；旧操作不会在新页面上被重新解释。
- 零值和故障下“确定”按钮仍可双击返回；无效的单击开始/恢复/调值由模型阻止。断连时允许本地暂停，故障时允许导航；解除故障不自动恢复计时。
- 业务计时使用完整 `performance.now()` 差值，动画限步不影响经过时间。时间倒退/非有限数被拒绝，角度样本 TTL 为 250 ms。该 TTL 不修改 STM32 的通信保护。
- `observe()` 只更新模拟角度反馈，明确手动增量走 `turn()`，自动回转不会再次被计入手动减时。网页模拟理想目标跟随，不能据此声称真实编码器已能识别手动接管。
- `stopIntent` 是归一化反向止挡意图，不是安培、N·m 或已经下发的电机命令。

## 文件与复现

| 文件 | 职责 |
| --- | --- |
| `model.js` | 导航、应用状态、时钟、模拟坐标、只读观测、止挡和圈色 |
| `gesture.js` | 无 DOM 的单击/双击/长按分类 |
| `interaction.js` | 鼠标/触摸/键盘适配，前台与后台同步，SVG 渲染 |
| `index.html`、`style.css` | 照片表盘、菜单、应用画面与响应式布局 |
| `assets/summit-dawn.png` | 1254×1254 日照金山生成壁纸；仅用于桌面 |
| `verify-orbit.js` | 多圈正反转、前后层次、单指针、九个入口、占位边界和秒表隔离 |
| `verify-lighting.js` | 灯效编辑、屏内外预览、动态效果、亮度、故障/唤醒与前台优先级 |
| `verify-wallpaper.js` | 壁纸解码、分辨率、圆形裁剪、信息可见、熄屏和切页检查 |
| `model.test.cjs`、`gesture.test.cjs` | 纯模型与手势边界单元测试 |
| `verify-navigation.js` | 通过公开控件验证导航、后台、唤醒、竞态和取消 |
| `verify-interaction.js` | 原计时/音量/灯带回归，包含完整 12 秒加速周期 |
| `verify-touch.cjs` | Chromium CDP 触摸输入，外环和确定按钮的点击、双击、长按、取消及运行中调时 |
| `verify-background.cjs` | Chromium 冻结 2.2 秒、恢复前台后核对后台计时 |

从仓库根目录运行：

```powershell
node --test firmware-esp32/ui/preview/model.test.cjs firmware-esp32/ui/preview/gesture.test.cjs
agent-browser --session gl30-check open http://127.0.0.1:8768/firmware-esp32/ui/preview/
$gl30Code = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes((Get-Content -Raw -Encoding UTF8 firmware-esp32/ui/preview/verify-navigation.js)))
agent-browser --session gl30-check eval -b $gl30Code
```

每个浏览器脚本从重载的初始页面运行；应用回归将正文路径替换为 `verify-interaction.js`。本机 Windows npm 包装器的 stdin 路径曾未执行代码，所以采用 Base64 参数，`null` 不能当成通过。

触摸使用独立新页面：

```powershell
agent-browser --session gl30-touch open http://127.0.0.1:8768/firmware-esp32/ui/preview/
agent-browser --session gl30-touch set viewport 390 844
$gl30Cdp = agent-browser --session gl30-touch get cdp-url
node firmware-esp32/ui/preview/verify-touch.cjs $gl30Cdp
node firmware-esp32/ui/preview/verify-background.cjs $gl30Cdp
```

## 验证边界

这是浏览器软件，不包含真实天气接口、串口、电机命令、系统音量接口或 ESP-IDF 应用。本轮没有修改 H25/H26、C/LVGL、电气保护、CAD 或采购。自动回转/止挡是模拟，连续光带是理想扩散效果；实际力矩、手动接管、LED 光学与实屏时延需另行验证。
