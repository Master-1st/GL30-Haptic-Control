# Support

This is an actively developed learning project, not a commercial product with guaranteed support.

- Use [Discussions](https://github.com/Master-1st/GL30-Haptic-Control/discussions) for setup questions, design reasoning, ideas, and learning notes.
- Use the issue templates for reproducible software bugs, bounded feature requests, or hardware evidence/review.
- Use private vulnerability reporting for security issues or safety-gate bypasses.

When asking for help, include your operating system, commit, tool versions, exact command, complete error, and the evidence level involved. For hardware, also include revision, wiring, supply/current limit, instruments, and whether the motor was energized.

Please do not ask maintainers to approve an energized hardware test without enough information to evaluate the power path and stop conditions.
