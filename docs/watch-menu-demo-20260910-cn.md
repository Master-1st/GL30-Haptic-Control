## 当前行为

| 页面/操作 | 行为 |
| --- | --- |
| 桌面 | 本地时钟、日期、秒数，明确标注的示例天气 24°C 晴；未接入实时天气 |
| 桌面单击 | 进入菜单；首次默认选中计时器，后续保留当前应用选择 |
| 菜单转动/单击 | 转动只选择计时器或音量；单击打开所选应用 |
| 双击 | 应用→菜单→桌面；桌面原地保持，不先执行一次单击 |
| 长按 | 650 ms 后归类但不执行任何应用动作，释放不补发单击；第二次长按也会消耗待定的第一次单击 |
| 应用内单击 | 计时器开始/暂停/继续/完成后清零；音量静音/取消静音 |
| 后台计时 | 返回桌面、菜单或音量都继续，显示剩余时间和独立暂停/继续入口；前台旋钮不被后台计时驱动 |
| 到时 | 切入计时完成画面，取消旧手势；原本熄屏则保持熄屏 |
| 熄屏/故障 | 首次单击或双击仅唤醒；故障可导航，但不能开始/恢复/调值 |
| 直接控制 | 四侧快捷键、后电源键、右侧桌面/返回保留；Esc 可直接返回 |

短按释放后等待约 300 ms，用来区分单击和双击。第二次按下落在窗口内时暂停单击判定；转动、直接导航、输入状态变化、失焦或完成会取消旧手势，不将延迟操作解释到新页面。去抖为 20 ms，拖动阈值为 6 CSS px。零值和故障时“确定”仍可双击返回，无效的单击由模型阻止。

## 审查与范围

DeepSeek V4 Pro 与 Qwen3.8 对相同契约包提供了完整独立意见；主线程据反例明确了确认期间转动、完成优先、默认选中项和故障/熄屏下导航规则，并以实际用例闭合。详见 [审查裁决](../output/watch-menu-20260910/review-adjudication.md)。模型没有收到最终全部源码，不将意见表述为最终源码三方一致通过。

Spark 因额度受限未能参与，未重复尝试；Luna 负责 HTML/CSS，主线程完成 JS、单元测试回退和最终验收。当前运行文件的校验值见 [SHA-256 清单](../output/watch-menu-20260910/runtime-sha256.json)，前一版文件保存在同目录 `before/`。

已验证的是本地浏览器软件；天气为示例，音量为模拟。没有连接串口、下发电机力矩、生成/烧录 ESP 固件、移植 C/LVGL 或改变 CAD/采购。真实止挡力、自动回转跟随与手动接管，以及物理 LED 扩散效果仍未验证。本地刷新会重置网页模拟状态，未实现跨刷新持久化计时。
