# GL30：皮带手感与机构简化复核

2026-09-11。针对 R4 的传动和按压结构复核；不是 R5 模型发布。R4 STEP、几何验证、采购表和固件均保持原快照。

同日后续：用户已确认手中的电机没有可用中心通道。该约束已用于 [R5 机械修改](full-assembly-r5-20260911-cn.md)，继续使用偏置短同步带。下面的通道核查讨论保留为此前决策证据，不再将“等待确认通道”列为当前待办。

## 结论与取舍

短同步带仍能传递可编程阻力、段落和自动回转，不会使全部功能消失；但带体弹性、齿部变形、反转迟滞以及新增轴承/带轮的摩擦和惯量，会影响最细小的反馈。程度取决于实物与调校，不能由 1∶1 或 CAD 无干涉推导出“等同直驱”，也没有依据给出损失百分比。

此前为隐藏屏幕支架直接选择偏置带传动，缺少触觉保真这一轮取舍检查。现在明确：**低摩擦、低回差和反馈清晰优先于继续压缩外形；R4 是可供审查的空间布置，不是已经验收的最终触感架构。**

可以继续合并支座、限位座和固定件，但不把必要的双轴承、防倾导向和硬限位当成多余零件删除。若要大幅简化，恢复同轴直驱最有价值；前提是先证明现有电机总成内确有可用的固定屏柱/线束通道，并解决按压承载。当前资料还不足以认定这条路线可无改装实现，也不足以认定它永远做不了。

## 皮带具体影响什么

Gates 把同步传动的定位误差来源分为带体伸长、齿间隙和齿部变形。不同齿形、张紧和加工质量差别很大，不能用某个品牌的性能代替当前未选定的 2GT 带。[Gates 精密传动手册，印刷页 63–64](https://www.gates.com/content/dam/documents-library/catalogs/light-power-and-precision-manual.pdf)

以下是把这些传动特性应用到本旋钮的工程判断，尚无本机实测：

| 体验 | 带传动的潜在影响 |
|---|---|
| 无段落、轻阻尼 | 新增摩擦和齿部周期感可能掩盖小阻力变化；不把带轮额外惯量说成不存在 |
| 很细的段落、突然反向 | 弹性和反转迟滞使段落边缘变软或方向切换不够干脆 |
| 到零硬墙 | 电机端已到位时，手端仍可能压缩传动弹性，形成额外转角 |
| 自动倒计时回转 | 功能仍可实现，但低扭矩下的起动、低速均匀性及用户接管必须验证 |

原厂 AS5048A 在电机端。电机端角度不是独立测得的旋环输出角度；传动有弹性时两者存在差值。加入负载端编码器有助于观测这个差值，却不能消除物理柔顺性、摩擦或共振，还会增加电路和控制调试，当前不为追赶旧方案而直接追加。

用最小弹性耦合模型表达这一点：

\[
\tau_b=K_b(\theta_m-\theta_o)+C_b(\dot\theta_m-\dot\theta_o)
\]

\[
J_m\ddot\theta_m=\tau_m-\tau_b-\tau_{fm},\qquad
J_o\ddot\theta_o=\tau_b-\tau_{hand}-\tau_{fo}
\]

角度单位 rad，扭矩 N·m，刚度 K_b 为 N·m/rad，阻尼 C_b 为 N·m·s/rad。此线性耦合式还没有包含齿隙死区与迟滞，摩擦项也不能一概当作纯粘性摩擦。1∶1 不带来传动比平方的惯量放大，但仍增加带轮、带体等零件的惯量。

仅作需求例算：若在项目目标扭矩 0.06 N·m 下，允许传动弹性造成 0.5° 转角，则 K_b 至少约 6.88 N·m/rad；若只允许 0.1°，则至少约 34.4 N·m/rad。这两个角度是假设的需求，不是已冻结指标，更不是本条皮带的实测刚度。真实硬墙还受控制带宽、结构柔度及摩擦影响。

## 中心通道：纠正此前的过度断言

[CubeMars 当前官方页面](https://www.cubemars.com/product/gl30-kv290-gimbal-motor.html) 宣传 Ø6 中心孔，并提供带/不带编码器选项和不同下载文件；这不能单独证明带编码器完整总成具有同样的通行净空。

本轮重新直接读取仓库内原厂带编码器 STEP 的 7 个实体。其轴向是 X、全长 28.2 mm，径向外包络 Ø34.5 mm。沿中心放置 Ø3/4/5/6 圆柱进行分段几何检查，现有模型并没有给出整段贯通通道：实体5在 X=-23.7…-22.2 和 -19.2…-16.6 mm 存在对上述探针的实心阻挡；实体6的 X=-12.3…-9.1 mm 对 Ø5/6 有阻挡。这里的坐标只属于原厂原始 STEP，实体序号不代表定子、转子或编码器身份。[可复现几何记录](../outputs/01a08963-e2d7-71e2-a353-8710a44dc948/direct-drive-review/direct-drive-review.json)

这些结果只证明 **STEP 所表示的材料挡住了探针**。原厂简化几何、实际堵件身份、定转子关系以及带编码器实物能否穿线，必须分开判断。此前“编码器占据中部，因此不能同轴直驱”的定因说法过强，已修正。不能据此让用户拆、钻或移走电机零件。

同样不能以 R4 的 Ø8 屏柱、Ø8.8 从动轴内孔大于 Ø6，就认定直驱必然失败：这些是 R4 的设计尺寸，不是不可改变的产品要求。若实物孔畅通，可重新设计较细的薄壁支撑管；还要核对线束装配、径向余量、支撑刚度、绝缘和固定端。现阶段没有冻结更小的屏柱直径。

## 哪些简化值得做

| 方向 | 本轮判断 |
|---|---|
| 轴承座与按压承载架合并 | R4 已做成一个承力实体，不能重复计为尚可节省的零件 |
| 弹簧定位/限位座、键座和灯板托耳并入相应底板/外壳 | 有局部减件空间；需按打印/加工方式和装配顺序细化，不能只合并 STEP 分组就声称降本 |
| 从动带轮与中空轴一体 | 能减少连接界面，但单套定制带齿轴未必比标准带轮便宜；不直接采用 |
| 独立张紧轮 | R4 未设置，不能写成已经删掉一个不存在的零件；若保留皮带，可优先在电机安装位实现可控张紧，不盲目拉紧 |
| 删除一只轴承、删除防倾导向 | 不建议；容易把零件数量换成旋环晃动或按压偏斜 |
| 普通滑动键/花键实现直驱按压 | 不建议为“简单”采用；滑动间隙和卡滞直接污染反转手感，预紧结构又增加成本 |
| 薄片弹性支承＋压力检测替代大行程滑台 | 是可研究的简化路线；会改变检测电路、校准与弹性件设计，不是现有七开关方案的免改替换 |

[SmartKnob 原作者项目](https://github.com/scottbez1/smartknob) 使用空心电机连接固定屏幕，并用 PCB 弹性结构与应变检测判定按压，说明这类路线已有开源样机依据。该项目也明确提醒制作与装配并非即插即用；不能直接承诺移植到本机后偏心按压不晃、寿命合格或成本更低。尤其不能让电机原轴承、屏幕玻璃或电池承受未核定的手压载荷。

## 当前决定与最小验证

1. 保留已交付 R4 作为空间/装配参考，不改动已购电机、编码器或采购清单，也不宣布皮带手感已经达标。
2. 大改机构前只解决关键通道问题：对应带编码器型号的真实净空、阻挡件身份、固定屏柱安装路径及独立承压方式。通道可成立时优先评估同轴直驱；不能成立且不改电机总成时，保留短同步带是诚实的折中。
3. 保留皮带的最小手感验证是同一电机、相近旋环惯量下，对比直接驱动与装带后的低阻力、反向细段落、端点墙和自动回转。各自合理调校，不能用不适合新机构的旧增益制造差异；量化静态扭矩—相对转角、起动阻力和反转迟滞，并由用户判断可接受性。测试须另按既有硬件限值执行，本轮没有运行。

复核方式：主线程查阅原厂资料并裁决；本地助手重新检查供应商几何；DeepSeek V4 Pro 对传动取舍做独立分析。主线程未采用其“必须有 ≥Ø8.8 通孔才能直驱”的说法，因为那把旧设计尺寸错误地当成不可变需求。本轮没有新的 R5 CAD、实物触感或疲劳验收。
