## 当前接口冻结

- ESP32-S3 UART 能力按官方上限冻结为 `5,000,000 baud`，不使用原设计草案的 6 Mbaud。
- J1-11：ESP TX -> STM32 PB11 RX；J1-12：ESP RX <- STM32 PB10 TX。
- GP1 接隔离电源域的开漏故障线；GP0 首版 DNP；GP2 不允许外部驱动。
- ESP UART0 启动日志必须迁移或关闭，二进制链路不能混入文本。
