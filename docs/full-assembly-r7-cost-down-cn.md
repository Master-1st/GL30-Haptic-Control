# GL30 R7：单套加工与打印优化

本版沿用 R6 的 104×98 mm 底面积、收腰旋钮、抬高后面板、四侧键和 1∶1 短同步带。针对一套样机，将难加工的一体结构改成浅平板、同轴车削件、短打印夹座及直管/隔柱；导轨定位面继续保持一体。没有改变固件出力或进行电机操作。

## 已做入几何的改动

| 部位 | R6 的制造难点 | R7 的结构和工艺 |
| --- | --- | --- |
| 承力架 | 底板、两层轴承座、细长连接筋合成约31.5 mm高的一件；深处刀具和打印支撑难接近 | 浅平底板最高4.5 mm；独立连续轴承筒用车削完成主要回转面，两端仅作轴向孔加工。轴承筒和底板用止口及三颗M3夹紧 |
| 轴承定位 | 两座之间有开窗和细筋 | 同一筒内贯通Ø24名义孔，底肩、7 mm外圈间隔环及0.6 mm薄压环保持两个6901的13 mm中心跨度。公差和轴承轴向预紧仍需实测选定 |
| 固定屏柱 | 长斜管和异形底脚融合，打印细孔不易清理 | Ø8/Ø6×57.1 mm直管配左右短夹座；直管可截取、去毛刺；夹座开合，管路可从侧面清理和装入 |
| 电路板支架 | 约27.2 mm高的悬空横桥连长腿 | 最高2.2 mm的开口平托盘，加两只25 mm直隔柱；PCB A/B安装平面仍为Z29.2/44 mm |
| 导轨支架 | 外背脊比底脚缩进2.5 mm，侧卧仍会悬空 | 背脊加厚至与原底脚外面X44.5齐平，保留一处浅侧开让位口以避开侧键；导轨定位面保持。绕世界Y+90侧卧后打印高度8.5 mm，局部孔/让位面仍检查支撑 |
| 外壳与小字 | 复杂壳体若整体按CNC报价不划算；3.4 mm小字的凹刻需要细工具 | 外壳仍优先打印；小号GL30改为后处理表面印字/转印，不刻入打印实体，不另做铭牌 |

这种拆分会增加标准紧固件和装配步骤，但减少高难度一体毛坯及深处加工。两个轴承仍由一个连续筒定位，导轨基准没有拆成多块拼接。不能把零件种类增加或减少直接换算为加工费变化。

制造商的设计指南将深腔、细长特征、多次装夹和小字凹刻列为成本因素，并建议在适当情况下拆成简单零件后紧固装配。本版按这些因素修改实际几何；这不是本项目的供应商报价。[Protolabs CNC降本说明](https://www.protolabs.com/en-gb/resources/design-tips/how-to-reduce-cnc-machining-costs/)、[Protolabs Network工艺建议](https://www.hubs.com/knowledge-base/reducing-cnc-machining-costs-design-tips/)。

## 这一套的加工分工

1. **自行打印**：外壳、底盖、PCB托盘、屏柱夹座、侧键座和键帽。先用现有材料配置检查尺寸，合适后再考虑外观涂装。导轨架可先打印试装。
2. **简单车削/平板加工询价**：连续轴承筒、外圈间隔环、浅平承力板。承力板仍有1 mm编码器避让和1.5 mm局部导轨垫高，均是浅面特征。筒上螺孔由轴向钻攻完成；不能按“纯车一刀成形”报价。
3. **购买或截料**：8×6直管、25 mm M2隔柱、螺钉与螺母。网格里也给了直管/隔柱尺寸样，方便试装，不要求将金属标准件改为塑料长期使用。
4. **保留单独评估**：旋钮、输出轴、带轮与电机滑座。收腰外轮廓没有改成直筒。低矮36T带轮的成品适配、定子固定和转子连接仍需实际供应商尺寸，不应将占位轮齿和电机安装包络当作可直接下单的制造图。
5. **薄片件**：0.6 mm压环可由合适板材切割；打印件只验证孔位和空间。弹片的材料、固定根部和力—位移关系需样件确定。

先按分件和工艺分别询价。不要让加工方把整机STEP中的PCB、电池、光学件、螺钉包络及所有塑料件一起按铝件铣削报价。当前未取得加工商正式报价，因此不承诺节省金额或百分比，也不把R5的粗预算当作R7成交价。

## 新接口与装配

- 轴承筒底止口Ø18×1.2，对应底板Ø18.2孔；三处M3安装轴在局部(12,0)、(-12,0)、(0,-12) mm。孔位呈非共线三角形，避开固定屏柱夹座和后弹簧座。端面负责夹紧，止口负责中心定位；名义间隙不是金属最终配合公差，也不能保证FDM直接插合。
- 轴承筒用三颗M3×8；顶部压环用两颗M2×4。螺纹在CAD中使用导孔和螺钉包络表达，没有生成螺旋牙型。装配验证把这几处有意的螺纹啮合单独列出，不把其他实体重叠算作通过。
- 屏柱先放进两夹座，用M3×25与M3螺母横向夹紧，再以两颗M2×5从底盖固定。夹座名义孔Ø8.2，两半各向中心闭合0.1 mm；应按实物管径与打印收缩确认夹紧量。保留屏柱与旋转轴的径向间隙，夹紧不能把直管挤弯。
- 两只25 mm板柱用两颗M2×6从底盖固定。后部两颗M2×25穿过板堆后锁入隔柱，前部两颗M2×20配两只M2螺母固定。板堆原有13.6 mm间隔件的公差仍需匹配。
- 保留R6侧键装配次序：空壳先放键帽，再装双键座和开关，随后装内部机械和板件。新增底盖固定件均从外侧操作。

新增紧固件纳入检查时，发现原模型几处未详细处理的空间重叠，已随本版修正：托盘前横梁改为开口并收窄右边；屏柱底脚避让弹簧座；左后脚垫移动以让开板柱螺钉；内部制动模块的等体积空间预留前移2 mm。B板三个元件包络为避开固定螺钉微调了位置，未改变器件型号或BOM；这些板目前仍是未布线的机械占位。

按压弹片缩短前端并增加板柱避让口，仍是单片平面形状。其有效弹性发生变化，必须重新确定弹片固定和按压力，不能宣称按压手感已保持原值。旋转传动比、导轨定位面、轴承跨度、0.35 mm名义行程以及旋钮/屏幕位置保持。

## 打印与证据边界

打印件均以mm、100%导入，3MF仅含几何。建议先试承力板、轴承筒、左右屏柱夹座与PCB托盘；先查关键孔和止口配合，再打印整壳。不要强压轴承。19种分件中，侧键帽四只、PCB直隔柱两只，其余按需要各一只。切片和材料配置由用户自行选择，不提供G-code，也未连接打印机。

本包支持无电尺寸、布置和装配检查。轴承座配合、连接预紧、导轨紧固细节、电机接口、手感/刚度、回差、散热和寿命均没有实物验证。轴承筒等金属件的塑料尺寸样，不是带载替代件。
