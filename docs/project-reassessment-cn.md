# GL30 项目复盘与推进方案（2026-09-05 历史记录）

> **历史快照，不是当前操作手册。** 本页的 USB-only/尚未闭环、B1 按住、首测限值和旧审查任务状态仅描述当时条件，不应用于现在的硬件操作。2026-09-08 当前台架证据见 [H25 扩展验收](bench-validation-20260908-haptic25-extended-cn.md)；最新整体进展与开源借鉴审查见 [项目进展与借鉴方案](project-progress-review-20260908-cn.md)。保留历史失败、设计判断和数字几何检查，不将它们追改为后来的实测结果。

本轮是当前工程修订，不升版本、不推送 GitHub。目标仍是黑色旋环、蓝色短标、关机一体黑屏、浅银底座、隐藏侧键与前灯条的可编程力反馈终端。先证明手感，再完成无线产品；没有把长期功能删掉，也没有把台架成功当成整机完成。

## 1. 核心判断

项目的吸引力应是 **同一个旋钮能切换清晰档位、弹簧回中、阻尼、软限位等手感，且应用可以配置这些手感**。屏幕、天气和智能家居是它的应用，不是替代真实力反馈的展示页。

当前瓶颈已不是再选一种编码器、重复测所有电机参数或先塞满功能，而是：可靠固定实物 → 读到可信角度/电流 → 闭环输出可解释的短时转矩 → 测量并调好手感。保留已经跑过的 CubeMX/LL/Keil 工程和安全链，不重新搭框架。

采用“真实电机台架 + 产品结构持续细化”两条不同验收线。旧全尺寸打印样用于手指触达和外形，不承担 FOC 验证；新增三件式夹具才连接真实 GL30。

## 3. 本轮模型改动

### 3.1 可连接真电机的三件式夹具

[模型目录](../output/models/GL30_MOTOR_FIXTURE/)：

1. `01_base`：100×90 mm 底座，四支柱、台面夹持槽和固定线束槽。
2. `02_stator_plate`：68×62×3.5 mm 可拆电机板，出线缺口、厂家实际三孔角度；螺钉可从背面装入。
3. `03_rotor_grip`：Ø54 mm 收腰菱纹握环，轮毂和四支臂一体成型，用前侧四孔传扭；不靠没有连接结构的环帽/袖套接触面传扭。

中间不放假屏、不穿固定管、不自加磁环；保留编码器原装关系。它使用电机原有轴承，仅供轻握、低电流短时联调，不用于按压、强侧推、高速或额定/峰值转矩验证。夹具握环保持 Ø54 是为了让后续接近产品手指接触半径；若实测摩擦或惯量使低电流对齐困难，应先排查装配，再考虑减轻握环，不直接加大电流。

图纸 3-M3/4-M3 深度与 STEP 孔段深度存在差别，夹具采用 2 mm 名义伸入量，但必须用实物有效螺纹深度及打印厚度复核。详见[夹具装配说明](../output/models/GL30_MOTOR_FIXTURE/ASSEMBLY_CN.md)。厂家二维图用于孔位/包络参考，不作为本夹具打印后免检证明。[官方带编码器二维图](https://www.cubemars.com/images/file/202512/GL30%20with%20encoder%202D%20drawing.pdf)

### 3.2 整机外观不推翻，结构补缺口

- 保留 96×96 底座、26°工作面、黑色收腰 Ø54 旋环、蓝色短标、黑屏过渡肩、浅银底座、四个融入侧壁的键和前灯条。
- 底面改为可拆盖，89.4×89.4×3 mm，四处 M3 90°沉头座和壳体螺母槽；头部不再依赖突出底面的盘头螺钉。四孔中心 `(±40,-29)`、`(±40,14)`，单位 mm；试配 M3×10 沉头螺钉和 M3 螺母，不加底面垫圈，实际头径/座深须核实。
- 两处内部支架由仅相切的多实体改为有实际搭接的单实体。只修复几何断开，不声称薄壁支架强度已经通过。
- 产品环帽/袖套传扭连接、固定屏安装、中心穿线/支撑、独立轴承配合和轴向保持仍是 HOLD。**不能把台架夹具的电机直驱握环，直接当成固定屏整机结构。**

独立轴承暂保留为产品承载方案，不因为“已有电机轴承”立即删除，也不声称永远必须增加。厂家允许载荷与预期手指按压/侧推、寿命数据决定是否可简化。屏幕固定管能否通过 Ø6 中孔同样需要可用空间和线束关系确认。

## 4. 下一步，只补有判别力的验证

| 顺序 | 做什么 | 通过条件/下一阶段门槛 |
| --- | --- | --- |
| 1 装配 | 打印夹具三件，固定 GL30，手转确认静止面/旋转面，查螺钉伸入和线束 | 不顶底、不拖线、无肉眼可见松动/摩擦；夹具夹在台面上 |
| 2 信号 | 功率输出关闭时读 AS5048A，检查供电/电平、角度变化、错误帧；核对电流零点/故障信号 | 实际信号与当前手册一致，故障后能保持禁止输出 |
| 3 首次闭环 | 严格沿用当前 NUCLEO/TI 参数和联调顺序 | 方向/电角零点合理，短时电流跟随，不异常转动，停止和故障切断可重复 |
| 4 手感 | 以限幅档位、弹簧、阻尼、软限位为第一批；先测再调 | 手感可重复且无振荡、撞限位、异常温升；再根据证据提高工作范围 |
| 5 最小应用 | 屏幕状态 + 音量 + 定时器事件映射到已验证手感 | 从用户操作到主机/屏幕/力反馈有一次可重复端到端演示 |

首测配置不是产品最终性能：20 kHz PWM、Id 对齐 0.10 A、Iq 绝对值最多 0.10 A 且每段最多 2 s、矢量电压最多 0.30 V；继续保留按住 B1、心跳及故障切断。详细操作以联调固件/手册为准，不从其他产品板 40 kHz 配置复制参数。

按照厂家 Kt 粗算，0.10 A 对应约 3.8 mN·m；这是量级估算，电流定义、相序/角度误差、摩擦与惯量都会影响实测。这个阶段只证明低能量闭环可控，不代表已经做出有吸引力的产品手感。对齐失败先查原因，不因为“力小”直接改大限流。

无需首测前做全套磁场线性、偏心、Ke、L、峰值扭矩和寿命实验。只有通信错误、对齐失败、明显角度周期误差或电流/温升异常，才针对异常补测试。安全关断、正确角度和电流采样不能省。

## 5. 现在画板子画到哪一步

有 TI EVM 和 NUCLEO 后，先不打样另一块同功能 DRV 验证子板。已有子板文档保留作正式驱动页参考。

- 现在可以画：模块分区、接口命名、供电域、测试点、连接器和安装孔候选、STM32 调试接口；整理 TI/ST 参考电路与器件封装。
- 首测后再冻结：电流增益与 ADC 量程/滤波、PWM/ADC 采样窗口、故障链、接插件实物尺寸、真实布局和散热路径。不能凭台架杜邦线表现直接冻结正式 PCB。
- 无线电源沿用现有 3S 工程候选，但电芯/BMS/充电/回灌/续航还没验收。先用实验电源，分开验证动力母线回灌与逻辑电源稳定性，再集成电池。不把电池承担结构载荷或螺钉夹紧力。
- Waveshare 的电池接口是 1S 3.7 V 级接口，不能接整机 3S 电池；金属壳体中的天线空间及黑盖板透光/触控效果需要样件验证。[官方模块页面](https://www.waveshare.com/product/esp32-s3-touch-amoled-1.32.htm)

## 6. 功能承诺边界

| 优先级 | 内容 | 当前决定 |
| --- | --- | --- |
| P0 | 可调档位、回中弹簧、阻尼、软限位；安全停机 | 真实 FOC 通过后优先兑现，不用应用数量替代手感 |
| P1 | 音量/媒体、定时器/闹钟事件、显示当前配置 | 最小有线应用；声音提醒可配合电机提示，未宣称扬声器/蜂鸣器实装 |
| P2 | Home Assistant 灯光等实体、天气状态、无线通信 | 保留实施位置，需要真实适配/离线行为测试，不标作现在可用 |
| P2 | SmartKnob / X-Knob 配置转换 | 只映射有语义依据且本平台能安全表达的力反馈参数；不承诺任意文件原样运行或一样的手感 |
| 待定 | 无线全力反馈续航、体积再缩小、补偿表、更强/复杂纹理 | 由电流/热/噪声/机械空间等实测决定，不提前给性能保证 |

不做无力反馈设备的“兼容展示”对比。关机一体黑是光学目标，CAD 黑色渲染不证明玻璃、屏幕边缘和涂层在日光下看不见。

## 7. 适合慢慢研究的节奏

按每周 6–10 小时估计：第 1 周夹具与信号；第 2 周低电流 FOC；第 3 周第一批受限手感；第 4 周最小有线应用。遇到信号或热问题，后续顺延，不把时间表当作通过标准。

后续按月推进主板、固定屏机械、无线电源和整机集成。公开可复现 v1.0 仍以约一年为目标，完整里程碑见 [ROADMAP](../ROADMAP.md)。当前最有价值的反馈是打印后的孔位、螺钉实际伸入、手转摩擦和握环触感，而不是先打印一套昂贵正式外壳。

已采纳：轻握低载荷用途、实测定/转面、螺纹深度尺寸链、原装编码器不拆、台架与产品不同验收。未采纳：没有统计数据的打印成功率、笼统的“另加轴承必需”、无请求的无线充电，以及把固定支架和转动支架合成同一零件的歧义建议。实际模型中是**每个支架内部各自连通，两支架仍分别固定/转动**。

最强未解决风险是实物安装/载荷未知；若手转关系、可用螺纹或低电流摩擦不符合当前假设，先停止装配/通电，修正对应夹具接口。打印成功和长期安全没有可用概率保证。
