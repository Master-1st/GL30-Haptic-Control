## 2. AD 中实际怎么操作

1. 打开 R6 `.PrjPcb`，核对 `Project Options` 的网络作用域为 **Global**。七页跨页同名标签按这个作用域连接，不要改为依赖层次端口。
2. 按 A01～A07 复核，运行工程验证。对 34 条警告逐条记录处理结果；不要用批量 No ERC 把它们隐藏。C53/C54 为可选 DNP 元件，预留位置仍需检查。
3. 在项目中增加 `GL30_A_STM32_FOC.PcbDoc` 并保存。先准备下表四个自定义焊盘封装，并确认其余封装在本机可解析。
4. 在原理图编辑器选择 `Design → Update PCB Document`。在 ECO 中先 `Validate Changes`，检查每条失败项；修正缺封装或针脚不匹配后，再 `Execute Changes`。导入后逐个核对位号、焊盘编号和网络，DNP 直焊接口不能因为“不买连接器”而从 PCB 删除。
5. 用当前机械装配导出的板框和孔位建板形，设置层叠和高度禁区。先放安装孔和接口，再按下一节放器件。界面可在 `Design → Layer Stack Manager` 设置层叠；DXF 导入机械层后，只选闭合板边轮廓，再 `Design → Board Shape → Define from Selected Objects`。
6. 保存布局，导出顶视图、底视图、带外壳的 3D 装配视图和尺寸表。检查零件及线束装配后，再进入后续布线。当前保留飞线；布线未完成，所以不应把未连接网络的 DRC 当作投板放行。

上述 ECO 和板框操作对照了 [Altium 原理图到 PCB 同步说明](https://www.altium.com/documentation/altium-designer/sch-pcb)、[板框定义](https://www.altium.com/documentation/altium-designer/pcb/defining-board-shape)及[层叠管理](https://www.altium.com/documentation/altium-designer/pcb/defining-layer-stack)。

### 布局前要补的四个封装

| 位号 | 功能与焊盘编号 | 怎么定尺寸 |
| --- | --- | --- |
| J1 | 母线直焊：1 MOTOR_BUS、2 GND | 按实物电源线外径、导体直径及剥线方式定孔径/焊盘，旁边留线束应力释放空间 |
| J2 | 三相直焊：1 MOTOR_U、2 MOTOR_V、3 MOTOR_W | 按电机实际线材定孔径、间距；相序标定还没有实板验收 |
| J3 | 编码器直焊：1 GND、2 5V_ENC、3 MISO、4 MOSI、5 SCK、6 CS_N | 按六根实线定焊盘；这是 A 板编号，不能直接推定厂家插头的物理顺序 |
| JP1 | 两焊盘焊桥：1 BOOT0、2 3V3；默认断开 | 做可以人工短接、正常使用保持断开的焊桥，不增加采购连接器 |

这四项都是板上几何，不需要另买四个端子。没有实线尺寸时不能把孔径随意冻结；可先摆候选位置，但需要在布线前确认。

## 3. 板框和层叠怎么定

**先适配已经打印并加工回来的结构。** 测量安装柱坐标、螺丝头占位、板上下净高、线束出口和装配入口，把这些作为机械层/禁止布件区；同步带、轮、浮动按压件的整个运动包络也要避开。FFC 要能插拔，不能只保证插座本体不碰外壳。

`hardware/cad/pcb_packaging.py` 中的旧草案是 **PCB_1P2_20260910**：A/B 为 98×34 mm、1.2 mm 厚、四层；C 为外径 74/内径 56 mm 的带耳环形板、1.2 mm 厚、两层。**这些尺寸只是旧包络线索。** R21 仍标为名义几何、实物配合待核，尚未包含新的 PCB；不能直接把 9/10 板框当作本次最终加工尺寸。

A 板先按四层规划，适合这个功率、采样和 MCU 混合布局。层叠建议是本项目的布局起点，最终厚度、铜厚和介质由实际空间及板厂层叠一起确认：

| 层 | 放什么 |
| --- | --- |
| L1 顶层 | 主要器件、DRV 近端功率回路、极短去耦连接、必要信号 |
| L2 内层 | 控制/采样区域连续的 GND 参考，避免信号跨参考地缺口 |
| L3 内层 | 分区电源铜及必要信号；相线开关区域避免向安静模拟区扩展 |
| L4 底层 | 低速接口、允许放在底面的低矮器件、地铜；不得侵入支架接触面 |

不要为了省面积把晶振、模拟采样和开关节点上下叠在同一位置。A 板是 MCU 和 FOC 同板，不要再拆出一块 MCU 板。

## 4. 器件按什么顺序摆

下面是**功能分区示意**，没有指定实际左/右朝向，也不是已完成的 PCB：

```text
母线入口 J1 ── 大电容/近端去耦 ── DRV8316 U2 ── 三相出口 J2
                                      │
                      SOA/SOB/SOC → 隔离/滤波 → MCU ADC
                                      │
                     硬件比较器 → HARD_FAULT_N → BKIN

编码器 J3 ── 接口保护/串联电阻 ── STM32 U1 ── 板间 FFC J5/J6
                                  │
                         24 MHz 晶振、复位、SWD J4
```

1. **安装孔、线束出口和 J5/J6。** 它们决定能否装进去以及排线能否接好，先固定。
2. **J1/J2 和 U2 功率区。** DRV 靠近母线入口与三相出口，给 VM/GND/三相及散热铜留足空间。先紧贴相应引脚摆去耦，再摆大电容；不要最后在空位里塞去耦。
3. **电流信号及硬件保护。** SOA/SOB/SOC 的前级隔离靠近来源，末端 RC 靠近相应 MCU ADC 脚。比较器、默认上拉/下拉及 BKIN 路径留出短而清晰的通路，不能穿过相线和 Buck 开关区域。
4. **STM32、3V3/3V3A 和晶振。** U1 是 **STM32G474CET6，LQFP48、7×7 mm 本体、0.5 mm 脚距**，不要换成 UFQFPN48 或 NUCLEO 的 RET6。供电去耦靠近对应供电脚，24 MHz 晶振靠近 PF0/PF1；晶振下面及附近不放相线/Buck 开关连接。封装依据见 [ST 数据手册](https://www.st.com/resource/en/datasheet/stm32g474ce.pdf)。
5. **编码器、SWD、复位与剩余元件。** 调试插头在装机后仍要插得上；检查 M2/M3 螺丝头、FFC 翻盖、插线和烙铁空间，不能只看器件的外框。

## 5. 以后布线时重点看什么

本节是布局时需要预留的连接路径，**本轮不执行布线**。

- **DRV 功率环路和散热。** VM 旁路和母线大电容的回路尽量短；CPH/CPL、CP、AVDD、VREF 的小电容紧贴对应脚。三相使用有足够截面的铜，跨层电流通道不能只靠单个小过孔。U2 底部 EP 要按对应 GND 网络焊接，并为地铜、散热过孔和钢网开口设计留空间。不要把 EP 当悬空机械焊盘。这些原则来自 [TI DRV8316 数据手册第 11 节](https://www.ti.com/lit/ds/symlink/drv8316.pdf)。
- **回流路径。** R6 当前采用同一个 GND 网络。按功率回流和安静模拟回流安排位置与铜形，结合 TI 的 PGND/AGND 布局示例复核连接；不能擅自改成两个不连接的地，也不要在 MCU/ADC/SPI 的参考地下面随意开缝。
- **模拟与保护。** 电流、母线、NTC 采样远离三相和 `BUCK_SW`；ADC 末端滤波回地就近，BKIN 硬件故障链要能直接工作，不依赖 ESP32 或软件停机指令。
- **UART/SPI/FFC。** 沿短路径安排参考地，避免跨相线、母线铜和分割区。FFC 每根线按脚号复核，不能凭“同面/异面”商品名称认定方向正确。
- **线宽与间距。** 普通信号、模拟、母线、三相和故障网分别建 Net Class。母线/相线按确定的铜厚、允许温升、连续/峰值电流、路径长度和并联过孔计算，制造下限再按选定板厂工艺校验；目前不能给一个通用线宽作为出力能力保证。

## 6. 与当前固件对应的关键脚位

以下是**产品 CET6**接口，不是 NUCLEO 台架针脚；精确网络连接以 R6 原理图为准。

| 功能 | STM32 管脚 | 对应硬件 |
| --- | --- | --- |
| 三路高侧 PWM | PA8/30、PA9/31、PA10/32 | TIM1 CH1/2/3 → DRV INHA/B/C |
| 三路低侧 PWM | PB13/27、PB14/28、PB15/29 | TIM1 CH1N/2N/3N → DRV INLA/B/C |
| 电流采样 | PA0/8、PA1/9、PB0/16 | SOA/SOB/SOC 隔离及 RC 后进入 ADC |
| 母线/温度采样 | PB1/17、PB2/18 | ADC 母线倍率 11；NTC 10k/B3950 |
| 硬件关断 | PB12/26 | `HARD_FAULT_N`，TIM1 BKIN，低有效 |
| 关桥控制 | PA3/11 | 开漏 `DRV_DRVOFF`；上拉/释放关桥，拉低允许 |
| 驱动休眠 | PA12/34 | `DRV_NSLEEP`，上电默认低 |
| 电机母线请求 | PB9/46 | `MOTOR_PWR_EN`，上电默认关闭 |
| 强制制动 | PA2/10 | `BRAKE_FORCE` → B 板，只要求开启制动 |
| 驱动 SPI3 | PB3/40、PB4/41、PB5/42、PB6/43 | SCK/MISO/MOSI/CS，当前固件 5 MHz |
| 编码器 SPI1 | PA5/13、PA6/14、PA7/15、PA4/12 | SCK/MISO/MOSI/CS，当前固件 Mode 1、16 位、2.5 MHz |
| 与 ESP32 通信 | PB10/22 TX、PB11/25 RX | 经电源域缓冲交叉到 ESP GPIO44 RX、GPIO43 TX；5 Mbps、8N1 |
| 板间 I²C | PA15/39、PB7/44 | SCL、SDA；当前固件 400 kHz |
| SWD | PA13/37、PA14/38、NRST/7 | J4 的 SWDIO、SWCLK、NRST |
| 不引出 | PC14/3、PC15/4、PA11/33 | **R6 明确 NC，无测试焊盘；ADC 使用内部 TIM1 TRGO2/OC4 触发** |

旧 `board_config.h` 的描述表仍把 PA11 标为 AF11/CH4，部分历史接线文档也仍保留测试焊盘描述。这里区分内部定时器功能与 R6 外部连接：**不要因此在板上恢复 PA11、PC14、PC15 的测试点或触发走线。** 该描述表的同步核定属于后续代码维护，本次没有改动冻结固件源码。

### J4：单排 5P、2.54 mm 调试口

| 脚 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| 信号 | 3V3/VTREF | SWDIO | GND | SWCLK | NRST |

一脚方焊盘。VTREF 是目标板电压检测，不接 ST-LINK 的 5V 或电源输出。沿用本机 R6 派生封装：完成孔径 1.02 mm、焊盘 1.70 mm。这个排列是本项目单排接口，不能按旧版 2×5 Cortex 插座的位置连接。

### J5/J6：均为 FH12-10S-0.5SH(55)，10P、0.5 mm

R6 库已核对 10 个信号焊盘及两片固定焊盘；固定焊盘 11/12 不是额外信号。下面是 A 板原理图脚号，不代表 FFC 到另一端必然同号。

| 脚号 | J5：A↔B | J6：A↔C/ESP 转接 |
| --- | --- | --- |
| 1 | 5V_LOGIC | GND |
| 2 | GND | ESP_UART_RX |
| 3 | I2C_SCL | ESP_UART_TX |
| 4 | I2C_SDA | GND |
| 5 | GND | SYS_FAULT_N_ESP |
| 6 | BRAKE_FORCE | I2C_SCL |
| 7 | HARD_FAULT_N | I2C_SDA |
| 8 | MOTOR_PWR_EN | 3V3_AUX |
| 9 | 3V3_AUX | 3V3_ESP |
| 10 | GND | GND |

A 板自己的 `3V3/3V3_AUX` 与 `3V3_ESP` 是不同电源域，不因为同为 3.3V 就并联稳压器输出。显示模组的 12P 接口经 C 板转接，不能直接插 A 板的 10P 接口。接触面、针一方向、实际排线连续性及原厂编码器小板去耦仍需按实物核对。
