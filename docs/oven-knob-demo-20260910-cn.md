## 实现与验收标准

| 用户要求 | 实现 |
| --- | --- |
| 音量对齐 | 33% 对应 118.8°，屏内 0.33 圈、外光带前端与模拟轴同坐标；喇叭图标按真实 SVG 包围盒居中 |
| 连续灯带 | 原离散可见灯段移除，改为连续 SVG 弧和柔光；无位图、Canvas、图片生成或新增依赖 |
| 蓝色前端、后方铺色 | 前端固定蓝色，经过部分为当前圈色；上一完整圈在未覆盖部分保留其颜色 |
| 内部多圈不同颜色 | 六圈分别采用橙、金、绿、紫、玫红、浅柠黄；外光带当前段匹配内圈颜色；完整圈不闪成空的新圈 |
| 小时分钟秒 | 屏幕、右侧时间及后台计时统一 HH:MM:SS；滑块刻度仍以分钟说明范围 |
| 烤箱式自动回转 | 本地单调时差推进倒计时，值直接映射模拟角度；位置观测为只读，不会把回转再次算成手动扣时 |
| 运行中手动调整 | 手动增量直接修改剩余时间，不从原始截止时刻覆盖；运行保持运行，暂停保持暂停，到零完成 |
| 零点受阻 | 到零给短暂止挡提示，继续逆转则钳位数值、显示反向止挡意图与轻微回弹；无隐藏负积累，反转第一步立即增值 |
| 完成/熄屏/故障 | 完成取消旧手势；音量后台计时到时回计时页；已熄屏时仍保持熄屏；失联隐藏位置、故障暂停且需手动恢复 |

预设和模式切换会同步模拟位置。真实电机的限速跟随、外力识别、接管与位置误差反馈尚未实现；网页中的理想跟随不能当作实测角度或已经下发电流。`stopIntent` 仅为 [-1,1] 的示意输出，没有 N·m/安培含义，没有串口/电机接口。

## 独立模型审查与裁决

本次使用同一 [规范任务包](../output/oven-knob-20260910/review-packet.txt) 发给两个模型；主线程在读取外部结果前保存了 [独立判断](../output/oven-knob-20260910/main-independent-review.txt)。

- DeepSeek V4 Pro/high：任务 `20260910051856-9f0d6690ad45` 完成，`finish_reason=stop`，约 104.6 秒；[完整意见](../output/oven-knob-20260910/deepseek-review.txt)。条件性支持，重点提出完成事件/排队输入、手动修改被旧截止时间覆盖、完整圈边界和零点负积累。
- 主线程裁决：网页按事件进入处理函数的时间结算，不回放延迟到达的旧操作；到时先取消旧手势，新手势才可设时。没有异步增量回放队列，也没有从旧 endTime 重算覆盖新值。上述边界已由模型、51 项浏览器检查及触摸回归验证。整圈使用完整双段 SVG 圆弧，蓝头为独立非零短弧。
- 千问：任务 `76336921b84b` 自然完成，`finish_reason=stop`，约 1218.4 秒；[完整意见](../output/oven-knob-20260910/qwen-review.txt) 初始判断为“需先修复”。其关键反例为前台音量/后台计时争抢坐标、完成与手动输入的顺序、换圈浮点边界，以及旧手势继续生效。
- 对千问意见的裁决：模拟轴只跟随前台值，音量前台时后台仅推进逻辑时间，已由模型和浏览器验证。到时采用明确的“先结算时间、完成则取消旧操作”规则；补上取消方向键连发状态的处理，防止音量页按住的方向键在计时完成接管后修改新计时。反向完整圈采用未取模数值并按毫秒落值，微小输入误差不会产生幽灵圈。千问提出的零点负向动作对应负力意图未采纳：本实现正方向为顺时针，因此阻止负向越界的反向意图为正，且无物理单位。

两模型本轮收到的是相同的交互规范与代码事实摘要，并非修改后的完整源码；未声称二者再次独立批准最终代码。该次可逆浏览器变更的争议已由明确规则与可执行反例裁决，没有追加第二轮。最终接受结论由主线程负责，硬件控制方案不在本次放行范围。

## 修改范围与仍需实物验证的内容

运行代码集中于 preview 的 `model.js`、`interaction.js`、`index.html` 和 `style.css`。Luna 仅负责 HTML/SVG/CSS；主线程验收其文件和实际 SVG 几何。Spark 本会话已确认额度不可用，单元测试由主线程编写和运行。同步修改项目索引、全量手册、交互架构、UI README 与进度说明，首版验收保留为带历史标记的记录。

没有改电机/ESP 固件、现有电气保护、CAD 或 PCB，没有烧录或操作硬件。原 24 LED 首板数量约束保留，但连续扩散光带、蓝头辨识度、功耗/热以及真实零点手感和手动接管均需实物验证；不能复用旧“仅亮 1–3 颗灯”的功耗假设。真实触摸注入属于浏览器验证，未做物理手机或真实旋钮测试。
