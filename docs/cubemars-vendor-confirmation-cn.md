# CubeMars GL30 工厂编码器版确认清单

状态：`PARTIAL_INFORMATION_RECEIVED`

已确认或已取得：

- GL30 工厂编码器版实物已到货。
- 用户已确认编码器为 `AS5048A`、接口为 `SPI`；这决定了固件驱动方向，但还不是线束可直接上电的证据。
- 官方 STEP、二维 PDF、厂家参数表和性能曲线已归档；STEP 与仓库现有文件哈希一致。
- 供应商参数初值为 7 极对、12 V、`Kt=0.038 N·m/A`、线—线 `1.53 ohm / 330 uH`，详见 [到货参数基线](../hardware/motor-control/GL30_KV290_ARRIVAL_BASELINE_CN.md)。

仍需厂家书面补齐以下信息，才能冻结 PCB、编码器线束和机械终稿。

## 1. 编码器与线束

1. 工厂编码器版准确 SKU，以及内置 AS5048A 板卡/模块的原理图或 datasheet 修订号。
2. 编码器实际供电电压范围、典型/最大电流、逻辑电平和绝对最大值；不能只依据裸芯片手册猜整机线束。
3. 完整线序、线色、连接器厂家/料号、对插料号、线缆长度和屏蔽/接地要求。
4. SPI 模式、允许时钟、CS 时序、是否转发原始 AS5048A 奇偶校验和错误位。
5. 角度刷新率、端到端延迟、抖动、允许最大机械转速。
6. 上电状态、错误状态、绝对零位定义、正方向定义和掉线行为。
7. 是否完成工厂校准；编码器机械零位与电机电气角偏置及其批次公差。

## 2. 电机参数

1. 曲线标题 `KV290@12VDC`为何与参数表 `255 rpm/V`、空载 `3060 rpm @ 12 V`不一致。
2. `Ke=3.73 V/krpm`采用线—线还是相电压、峰值还是 RMS、在何种转速和温度下测得。
3. `2.13 A`和 `7.4 A`是相电流峰值、相电流 RMS 还是直流母线电流。
4. `7.4 A / 0.28 N·m`允许持续时间、占空比、起始温度、绕组温升和冷却条件。
5. `1.53 ohm / 330 uH`是否为线—线值，电阻温度和电感测试频率/转子位置。

## 3. 机械与载荷

1. 官方图中的 3-M3 面和 4-M3 面分别是定子固定面、转子输出面还是编码器出线面。
2. 两侧安装基准、螺纹有效深度和推荐紧固扭矩。
3. 编码器出线位置、方向、连接器包络和最小弯折半径。
4. 编码器版本是否完整保留 `Ø6 mm` 通孔；是否允许穿固定支撑管或线束，可用净直径是多少。
5. 电机允许的持续/峰值径向载荷、轴向载荷、倾覆力矩和轴承寿命条件。
6. 推荐的转子适配盘、定子固定方式、同轴度/端跳要求。
7. 当前官方 STEP/PDF 的版本号、公差和变更通知机制。
