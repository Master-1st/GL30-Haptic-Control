# CubeMars GL30 KV290 工厂编码器版确认清单

状态：`VENDOR_REPLY_REQUIRED`
用途：一次性取得 PCB、固件和机械终稿所需信息，减少正式样机前的猜测与返工。

## 请厂家书面确认并提供附件

### 1. 产品与电气

1. 工厂编码器版准确 SKU、编码器芯片/模块型号、编码器 datasheet。
2. 输出接口究竟是 SPI、ABI、PWM、UVW、模拟量还是其他；请给完整时序/协议。
3. 编码器供电电压范围、典型/最大电流、逻辑电平和绝对最大值。
4. 输出是推挽还是开漏，是否需要外部上拉/下拉，能否直接连接 3.3 V STM32 GPIO。
5. 线序、线色、连接器厂家与料号、对插料号、线缆长度和屏蔽/接地要求。
6. 分辨率/PPR、更新率、端到端延迟、抖动、允许最大机械转速。
7. 上电状态、错误状态、绝对零位/Index 定义、正方向定义。
8. 是否完成工厂校准；编码器零位与电机电气角之间的偏置和批次公差。

### 2. 机械与载荷

1. 官方图中的 3-M3 面和 4-M3 面分别是定子固定面、转子输出面还是编码器出线面。
2. 两侧安装基准、螺纹有效深度和推荐紧固扭矩。
3. 编码器出线位置、方向、连接器包络和最小弯折半径。
4. 编码器版本是否完整保留 `Ø6 mm` 通孔；是否允许穿固定支撑管或线束，可用净直径是多少。
5. 电机允许的持续/峰值径向载荷、轴向载荷、倾覆力矩和轴承寿命条件。
6. 推荐的转子适配盘、定子固定方式、同轴度/端跳要求。
7. 当前官方 STEP/PDF 的版本号、公差和变更通知机制。
8. 工厂编码器版可采购性、MOQ、交期和批次一致性。
