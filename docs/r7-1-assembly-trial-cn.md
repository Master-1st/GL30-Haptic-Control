# GL30 R7.1：导轨补实与装配试验准备

## 导轨中间为什么有缺口

斜脊和底脚交界处原来留有V形缺口，背面仍连为一个实体，但这处缺口没有必要保留。R7.1把底脚高度由22提高到26 mm，上表面从世界Z24提高到Z28，补实交界处。只增加约127.97 mm³材料，外包络和8.5 mm侧卧打印高度保持。

上方靠侧键的浅槽承担另一项作用：给右侧双键座和外壳安装台让位。试算直接封平这处浅槽，会与按键座重叠约76.19 mm³、外壳安装台重叠15 mm³。因此保留这处让位，不能把两处缺口一起封掉。

## 先做哪种试验

本次先做无电空间、孔位和部件配合检查。以前的19种模型是尺寸样，不是已补齐所有连接的完整运动机构。本次额外导出11种原整机已有的几何：输出轴、三臂架、屏幕托盘、后开关座、板间隔管、止挡、内圈隔垫、A/B/C假板及电池占位块。总计30种模型，每种均有STL、3MF、STEP。塑料尺寸样不证明其能替代金属承力件。

无需先购买电池、焊接控制板或加工整套金属外壳。电池位置可用纸板/泡沫块，板件用假板；电机与屏幕已有实物时用于核对，尚无实物时暂不为外壳试放重复投入。

## 哪些打印，哪些加工

| 路线 | 零件 | 安排 |
| --- | --- | --- |
| 直接3D打印试装 | 外壳、底盖、导轨支架、左右屏柱夹座、PCB托盘、侧键座及键帽、后开关座 | 先检查局部接口，再打印整壳；尚缺固定接口处不能仅凭摆放认为已装牢 |
| 先打印尺寸样，再决定金属加工 | 承力板、轴承筒、输出轴、三臂架、屏幕托盘、电机滑座 | 最终公差/固定方式补齐后再下加工单 |
| 简单车削/平板加工 | 轴承筒、输出轴、承力板、外圈间隔环 | 功能依赖配合和端面精度，不用普通FDM孔替代轴承精密配合 |
| 截料或薄片加工 | 屏柱直管、13.6 mm板间隔管、0.6 mm压环、0.7 mm内圈隔垫、止挡 | 管材和小薄片不必按复杂整块CNC报价；厚度与端面仍须匹配 |
| 可选外观件加工 | 收腰旋钮 | 本次先打印。确认尺寸、连接与握持后再考虑铝件与表面处理 |
| 先选成品并匹配接口 | MGN7C导轨滑块、同步带及36T带轮 | 导轨和同步带不用打印；带轮齿形/轮毂不能按当前光滑包络加工 |

## 完整手动运动装配前，还缺的真实接口

1. **导轨固定**：当前轨长35 mm，导轨与滑块、支架底部的孔距、数量和紧固件尚未完整表达。HIWIN MGNR7标准长度表从40 mm起；35 mm应向实际供应商确认裁切、孔位和端距。国产同尺寸件也须按供方图核对，不是随意购买50/100 mm后直接装入。[HIWIN轨长规则与尺寸表](https://www.hiwin.com/wp-content/uploads/Linear_Guideway-E-2.pdf)
2. **底盖紧固**：原包络是Ø2螺杆、长5.5 mm，壳体孔却为Ø2.2 mm，不能形成有效螺纹啮合。这次已明确标为待修正项，没有把这4颗包络写成可以直接买的“M2×5.5”。
3. **传动及轴向限位**：电机定子固定、转子接头、轮毂夹紧、输出轴与三臂架/旋钮的固定、挡圈槽和轴承预紧尚需补齐。普通标准36T轮未必满足当前Ø27、7.6 mm高的低矮空间。
4. **屏幕与按压链**：管端到托盘的抗扭固定、屏幕螺钉、后开关座固定、止挡固定、三弹簧的完整规格及按压弹片根部和力—位移关系仍缺。弹簧外Ø4.4、内避让Ø3、装高5.5 mm只是安装空间，不是可采购的完整弹簧型号。

因此，当前可以开始打印和部件配合试验；完整的“装牢后顺畅旋转、按压自动回位”试验还需要补齐上述接口。加工单中的待确认项不能用任意孔、公差或螺钉替代。

## 本次文件验证

- 与R7逐零件比较，仅导轨支架几何发生变化；补料约127.97 mm³，没有删减实体。
- R7.1全量23项几何检查通过，整机STEP回读为197个有效实体。检查没有覆盖紧固件能否真实锁紧、摩擦、强度或手感。
- 原19种分件和补充11种分件，均完成闭合网格、单连通性、STEP回读、体积及包络核对。
- 60个STL/3MF文件均通过Bambu离线导入，未报告网格修复。未切片、生成G-code或连接打印机。
- 清单为单sheet，数量区分装机需求、本次准备量和暂缓项。当前没有正式加工报价或实物装配结果。
