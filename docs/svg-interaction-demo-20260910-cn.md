## 已实现的行为

| MD 要求 | 当前实现与证据 |
| --- | --- |
| 黑色外旋环、固定圆屏与过渡环 | 手写 SVG 产品结构，只有外环纹理跟随模拟轴旋转；按压时浮动组件微移 |
| 4 侧键、独立后键、单 USB-C | 产品图和可操作侧/后键保留，USB-C 是外观示意 |
| 外环释放按压，玻璃不承载操作 | 原始按压去抖门；鼠标/触摸按下不启动、释放启动；玻璃点击无事件 |
| 一圈 60 分钟、多圈橙色屏内环 | 连续一整圈得到 60 分钟；90 分钟为一圈半，360 分钟为六圈；初始零时长 |
| 固定底座 24 RGB | 每 15° 一灯位，两邻灯权重插值；输入失效时所有位置光关闭；没有实体蓝标签 |
| 时间与真实角度分开 | 预设和倒计时均不改模拟轴角度；旋转仍更新轴相位，但运行/暂停不改时长 |
| 计时闭环 | 开始、暂停、继续、完成、清零；用完整本地单调时差计时，装饰动画的限步不影响业务时钟 |
| 熄屏体验 | 屏幕与灯环一起关闭，后台计时继续；第一次按压仅唤醒；手动旋转不自动唤醒或改时长 |
| 夸张弹性动效 | 沙漏/音量图形有衰减摆动与挤压回弹，运行落沙、完成勾选和扩散线；减少动态效果会关闭装饰动画 |
| 可操作演示 | 真实时钟默认 1×；12 秒演示显式标为 450×，结束/退出后恢复普通时钟，不覆盖正在进行的普通计时 |
| 现有音量交互 | 保留音量、静音和声波调节反馈，未连接电脑音量或音频输入；后台计时可见且可暂停/继续，到时自动回到计时完成画面 |

依赖为浏览器内建 API。没有新增运行时包、远端字体、图片 CDN 或图像生成素材。渲染素材在 HTML 的 SVG 定义和 JS 的确定性路径生成中；PNG 仅为浏览器验收截图。

- 千问首轮 `e08d743db680` 自然完成，`finish_reason=stop`；最终答案见 [千问首轮](../output/svg-demo-20260910/qwen-first.txt)。初始本地服务离线，经身份检查后恢复原 Qwen 服务，没有停止无关程序。
- 两方均支持纯前端状态模型加 SVG 的方案，要求将释放按压、丢样、防猜圈、熄屏和计时独立性落实为可执行测试。上表列出本轮实际结果。
- 主线程没有采纳 DeepSeek 的“熄屏任何输入都唤醒”及“完成只能按 RESET 退出”扩展限制：MD 明确的是熄屏短按仅唤醒、完成后旋转可返回设定。实现中熄屏是与计时正交的标志；完成后的按压明确标为清零重设，旋转只回到设定，不自动开始。
- 修复前的源码及证据送入第二轮同包交叉复核；首轮设计判断不代替代码验收。
- DeepSeek 第二轮通过独立 SSE 发送同包源码，运行至 300 秒客户端超时，未取得最终代码结论；[状态记录](../output/svg-demo-20260910/deepseek-final-state.json) 为 failed。没有把该次推理进度视为审查通过，也没有重复启动同一完整审查来消耗预算。

### 千问第二轮与主线程验收

千问任务 `6d422d86d9f2` 自然完成，`finish_reason=stop`，耗时约 902.5 秒；[完整最终意见](../output/svg-demo-20260910/qwen-final.txt) 为有条件通过。它发现：计时中切换到音量后，计时继续但状态与完成反馈被遮住，这是本轮实际修复的问题。

实现采用明确的后台计时：音量页显示剩余时间并提供独立暂停/继续入口，外环保持音量与静音语义；到时模型切回计时完成状态，保留熄屏标志，并取消跨越完成时刻的未完成手势。此行为由新增的 4 项模型回归及 HTTP/file 各 4 项浏览器检查验证，最终合计为 26 项模型测试和每种启动方式 34 项集成检查。千问没有再次审查修复后的版本；接受结论由主线程依据实际代码与复测作出。

其他意见逐项裁决：滑块设置 `step=any` 保留旋转产生的小数分钟；拖动阈值改为 6 CSS px，并以 3 px 抖动触摸验证短按。小于 20 ms 的接触反复按去抖契约处理，不计独立点击；减少动态效果每帧读取系统偏好，无需重复加监听器。显式“看一次完整演示”可唤醒并启动加速示例，与硬件式短按首次只唤醒的入口区分。

## 改动范围与限制

本轮直接替换旧 Canvas 网页，新增纯模型与验收文件，更新 UI README、项目索引、全量手册及总进度中的旧网页说明。旧预览三个文件的只读副本保留在 `output/svg-demo-20260910/before/` 供差异追溯，不作为运行兼容层。

没有修改或验证新的电机固件、保护阈值、UART 实链路、C/LVGL 移植、PCB/CAD、采购或制造。SVG 形状不是工程尺寸/载荷/光学验收；浏览器时钟与触摸结果不等于 ESP 硬件资格。本轮未运行与这些未改代码有关的固件测试，不复用 H25 资格来说明 Web 或 H26 实机状态。

真实工具限制：Spark 原生额度已耗尽，模型测试由主线程编写并验收；浏览器录屏导出因缺少 ffmpeg 失败，没有交付或宣称存在 WebM，演示以可操作网页和截图交付。自动可访问性工具返回全零计数，未将其算作有效审计通过；本报告只声明已实际检查的键盘、触摸与布局行为。
