# V7 硬件闸门

闸门必须顺序通过；失败时保留原始数据并停在当前层，不用更高电压、更大电流或软件滤波掩盖问题。

| 闸门 | 范围 | 放行证据 |
| --- | --- | --- |
| G0 | 厂家资料闭合 | 编码器接口/电压/线序/连接器/速率/校准；安装面/出线/通孔/载荷书面答复 |
| G1 | 原理图/CAD 设计评审 | 公共电路 ERC、保护链、官方 STEP 装配、真实线束包络、独立评审 |
| G2 | 不上电首件 | 阻值、方向、焊接、短路、默认上下拉、连接器、防反灌、机械干涉 |
| G3 | 3.3 V/SWD/保护静态 | 启动电流、时钟、复位、IWDG、无 PWM；过流/过压注入和 BKIN 关断 |
| G4 | 工厂编码器 | 供电/电平安全，角度连续、方向、分辨率、延迟、零位和错误注入 |
| G5 | 低压电机/FOC | 相序、极对数、电角零位，0.2 A 起步，电流环、deadline、回灌和温升 |
| G6 | 旋环机械 | 用户载荷、跳动、摩擦、回差、轴承/耦合、寿命循环和防尘间隙 |
| G7 | 整机 | UI/音频/通信负载、触觉、连续运行、故障注入、热与报告 |

## 当前门状态

- G0：`PARTIAL/HOLD`。实物、官方 STEP/PDF、参数表、性能曲线以及 `AS5048A + SPI`方向已取得；仍缺编码器供电/线序/连接器/校准、安装面功能和允许载荷。
- 电机被动到货检查（手感、三相 R/L、绝缘、已知转速反电势）可以立即做并归档，不需要越过 G4/G5。
- G4 未通过前不向编码器猜测供电、不进入编码器闭环；G5 未通过前不把厂家 2.13 A/7.4 A 写成已验证能力。
- CAD 的概念包络检查可在 G0 前继续，但不能替代 G0/G1。
- PCB、正式机械件和电机带转均不得越过对应 HOLD。

## 2026-09-08 台架续测与产品闸门的区别

- [H25 扩展验收](bench-validation-20260908-haptic25-extended-cn.md)记录 NUCLEO + TI EVM 的受限 ALIGN、IQ、八模式、STOP/失联关断和无出力通信回归。H8 的母线门故障与 H10 的位移资格失败保留为历史，不再称为当前 H25 失败。
- G5 仍仅为台架局部证据：没有外部电流/力矩计量、温升、回灌或外部 nFAULT 整链实测，不能整体勾选通过。
- 产品工程仅同步修正 ADC 时钟并完成独立构建，未烧录验证；`factory_encoder_pending` 仍有效。台架局部通过不能放行产品 G4/G5/G7，更不能代替外部保护链、整机负载、热、回灌和寿命验证。
- 305 mA 电源限流是用户报告、未经仪表核实，且不等同于相电流限制；软件 STOP 不代表外部电源已断开。
