# Code of Conduct

## Our commitment

We want this project to be a respectful place for engineers, makers, students, researchers, and first-time contributors to learn together. Participants are expected to be patient, precise, and constructive regardless of experience, identity, language, or background.

## Expected behavior

- Critique ideas, code, measurements, and evidence—not people.
- State uncertainty and distinguish fact, inference, simulation, and physical test.
- Welcome questions and explain safety risks without ridicule.
- Give credit, preserve licenses, and disclose relevant conflicts of interest.
- Keep personal information, credentials, and private vendor communication out of public threads unless sharing is authorized.

Harassment, discrimination, threats, deliberate deception, unsafe pressure, and publication of another person's private information are not acceptable.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile or a private security advisory when confidentiality is required. Maintainers may edit or remove content, close discussions, reject contributions, or restrict participation to protect the community. Enforcement decisions should be proportionate, documented where appropriate, and respectful of affected people.

This code applies in repository spaces and when representing the project elsewhere.
